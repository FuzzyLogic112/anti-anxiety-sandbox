# 反焦虑决策沙盘

把被家庭、稳定、比较缠住的决定，变成可拆解、可实验的沙盘。

**在线访问：** https://fuzzylogic112.github.io/anti-anxiety-sandbox/

## 能做什么

1. **写下决定**：把纠结原样写下来，点「拆解」。
2. **焦虑地图**：焦虑强度与构成、核心恐惧雷达、哪些是事实哪些是故事；父母反对的情绪权重单独标注，可切换「如果爸妈支持」。
3. **平行路径**：保守留任 / 谨慎试水 / 阶段性投入，含 1 年、3 年节点与压力曲线，可并排对比。
4. **最小实验**：3 个 7–14 天的实验，标明成本、对父母的影响和风险等级；内置安全垫计算器。
5. **反馈更新**：写下实验结果，重新评估三条路径，重点说明家庭压力与风险感知的变化。

## 说明

- 单文件 HTML（`index.html`），样式与图表来自 Tailwind CSS、Chart.js 的 CDN，打开时需要联网。
- 当前拆解结果为内置示例数据；替换代码中的 `analyzeDecision` 与 `reassessSandbox` 两个函数即可接入大模型。
- 页面不收集、不上传任何内容。

> 这个沙盘不替你做决定，它只是帮你把“怕让父母失望”和“怕错过机会”这些缠在一起的情绪，拆开看清楚。
